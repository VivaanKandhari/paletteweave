How the weave works

Deterministic farthest-point initialization seeds Lloyd clustering in RGB or OKLab. Each learned centroid is represented by a nearby sampled source colour to keep swatches in gamut. The output uses nearest-colour assignment in OKLab, optionally followed by Floyd–Steinberg error diffusion in RGB.

Displayed error is the root mean squared Euclidean distance in OKLab from source to output. It measures pixel colour differences, not artistic quality. Dithering can increase pixel error while changing texture. Palette centroids learn from sampled pixels; rendering uses the entire resized image.

Project scope and credits

Built for InnovArt 2027 on 15 October 2026. This is a working art tool using established algorithms; no new colour-science method or research novelty is claimed. AI tools generated the implementation and project materials. Image owners retain responsibility for permissions on images they use.

Colour conversion follows Björn Ottosson's OKLab definition. K-means and Floyd–Steinberg diffusion are established methods. Limitations include reduced working resolution, no alpha-channel preservation, basic sampling, and no professional print colour management.
